# Промпты набора «Паутина»

Способ: встроенный `image_gen`, без API. Для всех новых изображений использован `transparent_background: true`; `preview-pawn-v1.png` передан как референс материала и стиля. Каждый файл генерировался отдельным запросом. `wP.png` — копия утверждённого эскиза, его исходный промпт сохранён в `SET.md`.

## Общая часть

```text
Use case: stylized-concept. Create exactly ONE finished transparent PNG chess-piece sprite in the same product family as the reference pawn. Input image is STYLE REFERENCE ONLY for satin-plastic material, broad raised web lines, one small decorative eight-legged spider on the lower stem, soft studio highlights, round stepped base and friendly simplified chess-toy proportions. No human characters or faces, no costumes, no lettering or logos. True classic chess silhouette, easy to identify by a six-year-old at 48 pixels. Three-quarter FRONT view, same perspective and top-left lighting as reference. Entire object fully visible, centered on a square canvas, base bottom aligned at about 90 percent of height, minimum 7 percent transparent margin around object. The base occupies the same width as the reference pawn base, no extra pedestal/platform. Solid connected shape, no scattered accessories. Genuine transparent background with alpha, no floor, scenery or shadows outside the object. Do not reproduce the reference pawn's round head except when the requested piece is a PAWN. 
```
