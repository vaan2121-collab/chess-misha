# Картинки новых соперников

Для каждого нового соперника позже положи в его папку PNG-файлы:

```text
assets/opponents/<id>/normal.png
assets/opponents/<id>/think.png
assets/opponents/<id>/happy.png
assets/opponents/<id>/sad.png
assets/opponents/<id>/check.png
assets/opponents/<id>/win.png
assets/opponents/<id>/lose.png
```

Новые ID:

- `baldi` — Балди
- `sonic` — Соник
- `creeper` — Крипер
- `mario` — Марио
- `mundus` — Мундус

Если будет только `normal.png`, игра покажет его как резервное лицо для остальных состояний.
